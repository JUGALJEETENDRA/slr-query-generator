# LitSync Search Bridge

This local Chrome extension receives the Scopus and Web of Science queries
generated by LitSync at `http://127.0.0.1:8000` or `http://localhost:8000`.

## Load it in Chrome

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Select **Load unpacked**.
4. Choose this `extension` folder (the folder containing `manifest.json`).
5. Start LitSync and generate a query. Use the matching database button in
   LitSync to open its Advanced Search page, then click the extension icon to
   start the selected workflow.

For Scopus, the extension enters the query, runs the search, and attempts the
CSV export. For Web of Science, it enters the `TS=` query and runs Advanced
Search; use Web of Science's Export control to choose the export format and
records. You must be signed in and have the appropriate database access.

The extension stores only the latest generated query in Chrome's local
extension storage. It does not request, collect, or store database credentials.
